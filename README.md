# 失物管理局

中文诡异解谜探险游戏，纯调查导图版 0.9.0。

0.9.0 取消经营入口、员工分配、生产链、资源研究、挂机外出与离线补算；后台也不再运行生产或随机来访。旧案进度、证物、道具、等级、记录和展开枝叶继续保留。旧经营数据留在存档中兼容备份，不作为调查条件。

所有窗口保留同一张横向层级导图与 SVG 连线，不再在 850px 以下变成卡片列表。支持拖动空白处、触屏滑动、横向滚动、缩放、全图总览与回到左侧；重绘保持当前画布滚动位置。同房间普通枝叶一直留下，实物开合仅隐藏内部内容。顶部减少重复房间标题与说明，主线目标、当前位置与阶段线保留。

15 级资历全部转为调查奖励：Lv.3 关注证物，Lv.5 每案定心恢复稳定，Lv.7 手写独立札记，Lv.10 跨轮回保留关注对象，Lv.11 旧案批注，Lv.13 现场复核清单，Lv.14 第二次定心，Lv.15 结案余声。残响、深层阅读、证物比对、旧镜片和 4 / 8 / 12 级侧室保留。主线无需刷等级；首次证物 +8、机关步骤 +12、三案结案 +65 / +95 / +135 等奖励不变。

档案室改为结案回访与异常见闻。藏品是故事收藏，不再展示生产加成。实际完成第三案后，才能主动封存旧卷并重开；确认前导出旧存档。累计经验、等级、藏品见闻和旧版永久数据保留；Lv.10 后保留关注对象，不保留旧谜底。本轮案件、道具、记录、札记、枝叶、藏品与旧版本轮经营数据重置。音乐在现场、证物笔记和档案室之间连续播放。

## 已保留的导图与现场功能

本版加入九种现场实物的独立开合：配电箱、待认领抽屉、台灯、值班桌抽屉、磁带机电池盖、时间罐盖、外套衣袋、投影仪检修盖和原始卷宗夹。按钮明确显示打开／关上、点亮／关掉等操作，内部证物与操作随开合显示或隐藏，物件本身与其他分支保留。再打开会恢复此前展开的阅读入口，已获得道具、已记录证物与已修机关不回退；开合不奖励经验、不消耗道具，也不能绕过钥匙等主线门锁。开合状态支持本地自动存档、导出与导入，旧版已展开的内容会接到新的实物父节点。双击只阅读说明，不误开合；键盘 Enter 可直接开合。

原创低音量悬疑环境乐，以及木材、金属、塑料、玻璃、布料、纸张和机械开关的仿真开合声，由浏览器本地合成，不使用远程音频或第三方歌曲。播放器独立于页面渲染；切换现场、笔记、案卷和档案室不重新开始，静音后恢复也不重建轨道。顶部“声音”可分别关闭背景音乐或音效、调整总音量并保存设置。首次点击后启用，刷新或离开网站会停止。声音不是解谜必要信息。

本版将第一案的遮镜验证扩展为有实际现场变化的对照：遮镜后出现敲击，敲走廊墙面与敲镜框分别留下不同响应，两种比较均完成后才可揭开纸票。具体操作会改变镜面、纸票与登记簿的节点名称，并长出新的“现场变化”。这些附查不奖励额外经验，不构成新的主线门槛；离开大厅时取回纸票，返回后可重新遮镜继续比较。进度、观察与展开状态支持本地存档。

已完成节点、阅读枝叶和线路降低视觉强调，但不删除、不自动折叠、不重新排序；选中时重新突出。新观察保留暖色边框，快捷入口可定位到变化分支。导图使用轻量圆角节点、细连接端点与圆角折线；所有屏幕保留左侧现场和横向层级。

实际采用了 [Mind Elixir](https://github.com/SSShooter/mind-elixir-core) 的圆角连接算法并改为横向绘制，不引入编辑器运行时或 CDN。原版权与 MIT 许可随网站发布，见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)；节点外观为针对游戏重新设计。另参考了 React Flow 的节点与端点呈现方式，未复制它的界面代码。

本版补齐向导“这一步怎么做”，切换房间时定位到当前位置，展开节点时保持点击位置。阶段线按实际机关状态推进；完成节点与结果保留规则不变。长弹窗的关闭按钮保持可见，阅读枝叶沿用对应物品的局部氛围效果。

刷新沿用当前页面的值班身份，新开的页面仍需接管。每次保存重新检查权限，接管时读取最新进度，不补算离线经营。主存档损坏时尝试有效备份，并保留异常原文供导出；本地存储不可用时可临时游玩并手动导出。玩家进度不上传。

新游戏从一件证物开始，笔记、地图、道具、资历和档案室逐步显现。旧存档保留已有调查入口，但不再显示经营入口。

顶部放大镜提供本地帮助搜索，先展示三个常见问题，再按关键词查阅玩法说明，不调用聊天服务、不发送玩家问题。第一案打开通路后，可展开大厅的现场验证，对地面粉末、倒影与镜面遮挡进行对照观察；试错留下记录，不影响结案，也不能反复刷经验。

三个案件均以交互思维导图调查。单击地点前往、单击物品展开分支，双击才阅读文字；展开后单击“执行操作”才使用道具。Enter 展开，Shift+Enter 阅读。长说明收在独立入口，分支可以同时留在主画面。镜面、纸张、电力、水纹、回声和城市节点具有轻量局部点击效果，并支持系统的减少动态效果偏好。

地点与物品分支单击立即展开，无需等待双击判断。图内执行节点保留防误操作确认，分支上方另有立即生效的明确执行按钮；也可直接点击“阅读文字”。证物、道具和资历解锁后出现在顶部。只在点击位置显示氛围反馈，不晃动整张导图。

当前现场固定在导图最左侧，第一层分为现场证物、主线操作、可选附查和前往地点，第二层展示具体证物或操作，第三层提供阅读与执行入口。绿色主线、浅褐色可选附查、蓝灰色地点导航各自独立。亲自展开才长出枝叶，不自动收起或重新排序；完成的操作保留在原处供回看。按案件和房间保存展开状态。小屏幕横向移动画布，不改变层级布局。

顶部固定显示“案卷 › 当前房间 › 选择的节点”，四段阶段线只标记主线进度，不泄露谜底。主线目标与自由附查分别显示，附查不会覆盖主线方向。左侧的短句随实际发现或操作变化，详细现场和操作记录仍需主动阅读。展开本身不使用道具、不加经验、不改变随机结果；顺序机关的三个选项一起显示，不按正确答案排序。新手向导会高亮尚未展开的正确入口。帮助搜索包含分层导图、保留枝叶与位置说明。旧存档保留完成状态，但不会伪造上线前未保存的详细记录。

记录两件证物后可开启“证物连线”：依次单击两个证物，再选择规则核对、信息拼合、身份比对、逆向路线或先后排列。三案共支持十一条可验证关系，金色线只显示玩家已确认的关系。缺失的纸面信息仍须先通过现场操作揭示。连线不消耗资源、不额外奖励经验，不替代机关操作，也不是结案的强制条件。小屏幕保留节点选择、验证反馈及已验证关系列表。

本站仅使用 HTML、CSS、JavaScript 与本地图片。无需 API 密钥、账号登录或后台服务。

第一案新增完整的镜面附查。记录镜子与女人的证词后，玩家可保留两种暂定猜测；到长椅追问，在大厅留下粉末线，并分别让女人停住、迈步，同时观察地面与镜面。只有亲自完成两种条件的对照，才可确认或推翻解释。确认后的结论开放新的追问，女人会合上伞，长椅与大厅留下可回看的现场变化。猜测、观察、改判和追问均支持自动存档；附查不扣资源、不额外奖励经验，不是主线门槛，结案后也可回访。

证物用“新发现／待验证／已有结论”三个简短标记区分状态。验证操作收在“镜面附查”节点，详细文字仍需双击或主动阅读；主画面不展开整段观察文字。旧存档不会自动产生猜测、观察或新结论。

## 游玩

从 GitHub Pages 站点进入游戏，或下载完整项目后打开 `index.html`。

玩家进度保存在浏览器本地，不上传至 GitHub。更换网站地址、电脑或浏览器前，请在游戏“存档”菜单导出存档，再在新地址导入。建议定期备份。

## 发布

GitHub Pages 从 `main` 分支的根目录发布；`.nojekyll` 用于直接提供静态文件。后续提交到 `main` 会更新网页。
