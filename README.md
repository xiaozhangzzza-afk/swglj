# 失物管理局

中文文字解谜、异常调查与增量经营游戏，档案版 0.4。

本站仅使用 HTML、CSS、JavaScript 与本地图片。无需 API 密钥、账号登录或后台服务。

## 游玩

从 GitHub Pages 站点进入游戏，或下载完整项目后打开 `index.html`。

玩家进度保存在浏览器本地，不上传至 GitHub。更换网站地址、电脑或浏览器前，请在游戏“存档”菜单导出存档，再在新地址导入。建议定期备份。

## 发布

GitHub Pages 从 `main` 分支的根目录发布；`.nojekyll` 用于直接提供静态文件。后续提交到 `main` 会更新网页。

## 界面参考

排版方向参考 [Ink IF Story Template](https://github.com/RemyVim/ink-if-story-template) 与 [Sakura](https://github.com/oxalorg/sakura)，未复制其代码或引入第三方依赖。

现场图片由内置图片工具生成，只提供氛围；解谜必要信息均可通过文字取得。
