# Open-source notices

The rounded SVG connector in `diagram-edges.js` is adapted from the
`roundedVertical` implementation in Mind Elixir, transposed for the game's
left-to-right layout. The game does not include Mind Elixir's editor runtime.
The investigation card styling is game-specific; Mind Elixir and React Flow
were inspected as visual references.

Source: https://github.com/SSShooter/mind-elixir-core/blob/master/src/utils/generateBranch.ts
